1 Ίντα εν ο αλγόριθμος

Ένας αλγόριθμος εν μια δουλειά που πάει βήμα-βήμα, για να λύσει έναν πρόβλημα, με μετρημένα βήματα. Ένας σωστός αλγόριθμος πρέπει:

  • να παίρνει είσοδο (τίποτε ή περισσότερα δεδομένα),
  • να βκάλλει έξοδο (ένα ή περισσότερα αποτελέσματα),
  • να εν ορισμένος, δηλαδή να έσιει μέσα ξεκάθαρες οδηγίες,
  • κάθε οδηγία του να εν, μανιχή της, πολλά απλή,
  • να πιάννει ούλλες τες πιθανές εισόδους που μπορεί να έρτουν,
  • τζαι να τελειώννει σίουρα, σε μετρημένα βήματα.

Πρόγραμμα εν ο αλγόριθμος γραμμένος ξεκάθαρα σε μια γλώσσα προγραμματισμού. Έναν αλγόριθμο μπορούμε να τον περιγράψουμε με φυσική γλώσσα, με διάγραμμα ροής (flowchart), με ψευδοκώδικα, οξά κατευθείαν με κώδικα.

Όταν λύννουμε έναν πρόβλημα με τον υπολογιστή, συνήθως περνούμε που τούτα τα στάδια:

  1. Ανάλυση των δεδομένων του προβλήματος.
  2. Μαθηματική διατύπωση του προβλήματος.
  3. Σχεδιασμός οξά διάλεγμα του αλγορίθμου που ταιριάζει (συνήθως ένας πρόβλημας λύννεται με πολλούς διαφορετικούς αλγορίθμους).
  4. Γράψιμο του αλγορίθμου σε γλώσσα προγραμματισμού, δηλαδή γράψιμο του προγράμματος.
  5. Τρέξιμο του προγράμματος για συγκεκριμένα δεδομένα.
  6. Ερμηνεία των αποτελεσμάτων.

Σχεδόν κάθε αλγόριθμος χτίζεται που λίες βασικές αλγοριθμικές ενέργειες:

  • είσοδος / έξοδος δεδομένων·
  • πράξεις τζαι αναθέσεις τιμών σε μεταβλητές·
  • έλεγχος συνθηκών τζαι διάλεγμα δράσης·
  • επαναληπτικό τρέξιμο·
  • τερματισμός.

Το μάθημα, στην ουσία, εν η εξάσκηση στο να βάλλουμε τούτες τες ενέργειες μαζί για να φκάλλουμε λύσεις — τζαι να τες μεταφράζουμε που τη μια μορφή περιγραφής στην άλλη.

1.1 Παράδειγμα: Γραμμική Αναζήτηση (Linear Search)

Ας θωρήσουμε έναν ολόκληρο αλγόριθμο στες τέσσερεις μορφές που είπαμε: φυσική γλώσσα, διάγραμμα ροής, ψευδοκώδικα, τζαι κώδικα.

Πρόβλημα: Δίνεται μια λίστα με αριθμούς v τζαι μια τιμή-στόχος. Να ευρεθεί η θέση της τιμής-στόχου μέσα στη λίστα (οξά να φανεί ότι εν έσιει).

Ο πιο απλός αλγόριθμος: σαρώνουμε τη λίστα που την αρχή, στοιχείο-στοιχείο. Άμα εύρουμε τον στόχο, δίνουμε πίσω τη θέση του τζαι σταματούμε· άμα φτάσουμε στο τέλος τζαι εν τον ηύραμε, τότε εν έσιει. Εν χρειάζεται η λίστα να εν ταξινομημένη.

Σε φυσική γλώσσα

  1. Ξεκίνα που την πρώτη θέση της λίστας (θέση 0).
  2. Για κάθε θέση, με τη σειρά, ώστι να φτάσεις στο τέλος της λίστας:
    1. Άμα το στοιχείο σε τούτη τη θέση εν ο στόχος, ευρέθηκεν — τελείωσε τζαι δώσε πίσω τη θέση.
  3. Άμα έφτασες στο τέλος τζαι εν ηύρες τον στόχο, τότε εν έσιει μέσα στη λίστα.

2 Η Python

Η Python εν μια γλώσσα προγραμματισμού υψηλού επιπέδου, που:

  • δουλεύκει με διερμηνέα (εν scripting language), τζαι μπορεί να τρέξει είτε εντολή-εντολή σε διαδραστικό κέλυφος (shell), είτε σαν ολόκληρο αρχείο .py,
  • εν δυναμική ως προς τον ορισμό τύπου μεταβλητών (εν χρειάζεται να δηλώσουμε τον τύπο μιας μεταβλητής),
  • έσιει απλή σύνταξη, με υποχρεωτική στοίχιση (indentation) που ορίζει τα μπλοκ κώδικα,
  • έσιει μεγάλη πρότυπη βιβλιοθήκη (standard library) με έτοιμες συναρτήσεις.

Την έφκαλεν ο Ολλανδός Guido van Rossum στες αρχές της δεκαετίας του ’90 (πρώτη έκδοση Python 0.9.0, Φεβρουάριος 1991). Ύστερα ήρταν η Python 2.0 (2000) τζαι η Python 3.0 (2008, που εν ταιριάζει με την 2.x), που εν τούτη που χρησιμοποιούμε σήμερα.

Ένα πρόγραμμα Python τρέσιει με δκυο τρόπους:

  • διαδραστικά: γράφουμε εντολές μια-μια στο κέλυφος (shell) της Python, που τες διερμηνεύκει τζαι τες τρέσιει αμέσως·
  • σε λειτουργία script: γράφουμε ολόκληρο το πρόγραμμα σε ένα αρχείο .py τζαι το τρέχουμε ούλλο μαζί.

Σε τούτες τες σημειώσεις, κάθε φορά που πατάτε “Run Code” ολόκληρο το πλαίσιο τρέσιει σαν script.

Το σύμβολο # ξεκινά ένα σχόλιο: ό,τι εν στα δεξιά του, ο διερμηνέας εν το λοάρκαζει.

2.1 Μεταβλητές τζαι τύποι

Μια μεταβλητή εν ένα όνομα που δείχνει σε ένα αντικείμενο αποθηκευμένο στη μνήμη· το αντικείμενο έσιει μια τιμή τζαι έναν τύπο (type). Φκάλλουμε μια μεταβλητή με μια εντολή εκχώρησης (assignment): μεταβλητή = τιμή.

Στην Python εν δηλώνουμε τον τύπο: ορίζεται μανιχός του που την τιμή, τζαι μπορεί να αλλάξει άμα δώσουμε ύστερα τιμή άλλου τύπου.

Κανόνες για τα ονόματα. Ένα όνομα μεταβλητής:

  • ξεκινά με γράμμα οξά κάτω παύλα (_)·
  • έσιει μέσα μανιχά γράμματα, αριθμούς τζαι κάτω παύλες — όι κενά οξά τελείες·
  • εν μπορεί να εν δεσμευμένη λέξη-κλειδί (for, if, while, …).

Η Python ξεχωρίζει τα μιτσιά που τα κεφαλαία: το age τζαι το Age εν διαφορετικές μεταβλητές.

2.2 Είσοδος με την input

Σε ένα κανονικό πρόγραμμα Python, η συνάρτηση input('μήνυμα') διαβάζει δεδομένα που το πληκτρολόγιο τζαι πάντα δίνει πίσω συμβολοσειρά — ακόμα τζαι άμα ο χρήστης γράψει αριθμό. Για να δουλέψει σαν αριθμός, πρέπει να μετατραπεί με τες συναρτήσεις int() οξά float():

age = input('Δώσε την ηλικία σου: ')   # η age εν πάντα str
age = int(age)                          # μετατροπή σε int

οξά, πιο σύντομα, με τες δκυο κλήσεις μαζί:

age = int(input('Δώσε την ηλικία σου: '))

3 Σύνοψη

Τούτη την εβδομάδα είδαμε:

  • Ίντα εν ο αλγόριθμος, τζαι τες τέσσερεις μορφές περιγραφής του (φυσική γλώσσα, διάγραμμα ροής, ψευδοκώδικας, κώδικας) — με τη γραμμική αναζήτηση σαν παράδειγμα.
  • Μεταβλητές τζαι βασικούς τύπους δεδομένων (int, float, str), τζαι ότι η Python εν δυναμικά τυποποιημένη.
  • Ότι μια μεταβλητή εν στην πραγματικότητα μια αναφορά σε ένα αντικείμενο (id, is), όι ένα “κουτί” με τιμή.
  • Είσοδο/έξοδο με input/print, τζαι μετατροπές τύπου (int(), float(), str()).
  • Μορφοποίηση εξόδου: τους τελεστές sep/end, τη συνάρτηση format, τζαι τα f-strings.
  • Γραφική έξοδο με το matplotlib (plt.plot, plt.scatter, plt.bar, plt.show) — ένα εργαλείο που εννά χρησιμοποιούμε σε ούλλο το μάθημα.
