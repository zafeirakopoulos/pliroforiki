1 Το νόημαν του αλγορίθμου

Έναν αλγόριθμον λέγομε μίαν δουλείαν ντο πάει βήμαν-βήμαν, για να λύν’ έναν πρόβλημαν, με μετρεμένα βήματα. Ένας σωστός αλγόριθμος πρέπ’:

  • να παίρ’ είσοδον (τιδέν ή περισσότερα δεδομένα),
  • να βγάλ’ έξοδον (έναν ή περισσότερα αποτελέσματα),
  • να έν’ ορισμένος, ατό θα πει να έχ’ απέσ’ λόγια ξεκάθαρα,
  • κάθαν οδηγία ατ’ να έν’, μαναχόν ατ’, πολλά απλή,
  • να πιάν’ όλεα τα λογιών εισόδους ντο εμπορεί να έρταν,
  • και να τελειών’ σίγουρα, σε μετρεμένα βήματα.

Πρόγραμμαν έν’ ο αλγόριθμος γραμμένος ξεκάθαρα σε μίαν γλώσσαν προγραμματισμού. Έναν αλγόριθμον εμπορούμε να περιγράφομ’ ατον με φυσικήν γλώσσαν, με διάγραμμαν ροής (flowchart), με ψευδοκώδικαν, ή κατ’ ευθείαν με κώδικαν.

Όντες λύνομε έναν πρόβλημαν με τον υπολογιστήν, συνήθως περνούμε ας ατά τα στάδια:

  1. Ανάλυση ας τα δεδομένα του προβλήματος.
  2. Μαθηματικήν διατύπωσην του προβλήματος.
  3. Σχεδιασμόν ή διάλεγμαν αλγορίθμου ντο ταιριάζ’ (συνήθως έναν πρόβλημαν λύεται με πολλούς διαφορετικούς αλγορίθμους).
  4. Διατύπωσην του αλγορίθμου σε γλώσσαν προγραμματισμού, ατό θα πει γράψιμον του προγράμματος.
  5. Εκτέλεσην του προγράμματος για συγκεκριμένα δεδομένα.
  6. Ερμηνείαν ας τα αποτελέσματα.

Σχεδόν κάθαν αλγόριθμος χτίζεται ας ολίγες βασικές αλγοριθμικές ενέργειες:

  • είσοδος / έξοδος δεδομένων·
  • πράξεις και αναθέσεις τιμών σε μεταβλητές·
  • έλεγχος συνθηκών και διάλεγμαν δράσης·
  • επαναληπτικήν εκτέλεσην·
  • τερματισμός.

Το μάθημαν, σην ουσίαν, έν’ η εξάσκηση σο να συνθέτομε ατές τις ενέργειες σε λύσεις — και να μεταφράζομ’ ατες ας τη μίαν μορφήν περιγραφής σην άλλεν.

1.1 Παράδειγμαν: Γραμμικήν Αναζήτησην (Linear Search)

Ας ελέπομε έναν ολόκληρον αλγόριθμον σις τέσσερεις μορφές ντ’ είπαμε: φυσικήν γλώσσαν, διάγραμμαν ροής, ψευδοκώδικαν, και κώδικαν.

Πρόβλημαν: Δίγεται μία λίστα ας αριθμούς v και μία τιμή-στόχος. Να ευρεθεί η θέση τη τιμής-στόχου απέσ’ ση λίσταν (ή να φανεί ότι κι έν’ ακεί).

Ο πιο απλός αλγόριθμος: σαρώνομε τη λίσταν ας την αρχήν, στοιχείον-στοιχείον. Άμα εύρομε τον στόχον, δίγομε οπίσ’ τη θέσην ατ’ και σταματούμε· άμα φτάνομε σο τέλος και κι εύραμ’ ατον, τότε κι έν’ ακεί. Κι χρειάζ’ η λίστα να έν’ ταξινομημένη.

Σε φυσικήν γλώσσαν

  1. Αρχίνα ας την πρώτην θέσην τη λίστας (θέση 0).
  2. Για κάθαν θέσην, με τη σειράν, έως το τέλος τη λίστας:
    1. Άμα το στοιχείον σ’ ατήν τη θέσην έν’ ο στόχος, ευρέθεν — τελείωνε και δώσ’ οπίσ’ τη θέσην.
  3. Άμα έφτασες σο τέλος και κι εύρες τον στόχον, τότε κι έν’ απέσ’ ση λίσταν.

2 Η Python

Η Python έν’ μία γλώσσα προγραμματισμού υψηλού επιπέδου, ντο:

  • δουλεύ’ με διερμηνέαν (έν’ scripting language), και εμπορεί να εκτελεστεί είτε εντολήν-εντολήν σε διαδραστικόν κέλυφος (shell), είτε άμον ολόκληρον αρχείον .py,
  • έν’ δυναμικήν ως προς τον ορισμόν τύπου μεταβλητών (κι χρειάζ’ να δηλώνομε τον τύπον μιας μεταβλητής),
  • έχ’ απλήν σύνταξην, με υποχρεωτικήν στοίχισην (indentation) ντ’ ορίζ’ τα μπλοκ κώδικα,
  • έχ’ μεγάλην πρότυπην βιβλιοθήκην (standard library) με έτοιμες συναρτήσεις.

Εφτιάχτεν ας τον Ολλανδόν Guido van Rossum σις αρχές τη δεκαετίας του ‘90 (πρώτη έκδοση Python 0.9.0, Φλεβάρης 1991). Υστερνά έρθαν η Python 2.0 (2000) και η Python 3.0 (2008, ντο κι ταιριάζ’ με την 2.x), ντο χρησιμοποιούμε σήμερα.

Έναν πρόγραμμαν Python τρέχ’ με δύο τρόπους:

  • διαδραστικά: γράφομε εντολές μίαν-μίαν σο κέλυφος (shell) τη Python, ντο διερμηνεύ’ ατες και εκτελεί ατες αμέσως·
  • σε λειτουργίαν script: γράφομε ολόκληρον το πρόγραμμαν σε έναν αρχείον .py και τρέχομ’ ατο συνολικά.

Σ’ ατές τις σημειώσεις, κάθαν φοράν ντο πατείτε “Run Code” ολόκληρον το πλαίσιον εκτελείται άμον script.

Το σύμβολον # αρχινά έναν σχόλιον: ό,τι έν’ δεξιά ατ’ κι το λογαριάζ’ ο διερμηνέας.

2.1 Μεταβλητές και τύποι

Μία μεταβλητή έν’ έναν όνομαν ντο δείχν’ σε έναν αντικείμενον αποθηκευμένον ση μνήμην· το αντικείμενον έχ’ μίαν τιμήν και έναν τύπον (type). Εφτάγομε μίαν μεταβλητήν με μίαν εντολήν εκχώρησης (assignment): μεταβλητή = τιμή.

Ση Python κι δηλώνομε τον τύπον: ορίζεται μαναχόν ατ’ ας την τιμήν, και εμπορεί να αλλάζ’ άμα υστερνά δίγομε τιμήν άλλου τύπου.

Κανόνες για τα ονόματα. Έναν όνομαν μεταβλητής:

  • αρχινά με γράμμαν ή κάτω παύλαν (_)·
  • έχ’ απέσ’ μαναχόν γράμματα, αριθμούς και κάτω παύλες — όχι κενά ή τελείες·
  • κι εμπορεί να έν’ δεσμευμένη λέξη-κλειδί (for, if, while, …).

Η Python ξεχωρίζ’ τα μικρά ας τα κεφαλαία: το age και το Age είναι διαφορετικές μεταβλητές.

2.2 Είσοδος με την input

Σε έναν κανονικόν πρόγραμμαν Python, η συνάρτηση input('μήνυμαν') διαβάζ’ δεδομένα ας το πληκτρολόγιον και πάντα δίγ’ οπίσ’ συμβολοσειράν — ακόμα κι άμα ο χρήστης γράφ’ αριθμόν. Για να δουλέψ’ άμον αριθμός, πρέπ’ να μετατραπεί με τις συναρτήσεις int() ή float():

age = input("Δώσ' την ηλικίαν σ': ")   # η age έν' πάντα str
age = int(age)                          # μετατροπή σε int

ή, πιο σύντομα, με τις δύο κλήσεις μαζί:

age = int(input("Δώσ' την ηλικίαν σ': "))

  • Είσοδον/έξοδον με input/print, και μετατροπές τύπου (int(), float(), str()).
  • Μορφοποίησην εξόδου: τους τελεστές sep/end, τη συνάρτησην format, και τα f-strings.
  • Γραφικήν έξοδον με το matplotlib (plt.plot, plt.scatter, plt.bar, plt.show) — έναν εργαλείον ντο θα εφτάγομε σε όλον το μάθημαν.
