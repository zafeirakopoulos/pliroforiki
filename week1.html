1 Τι είναι αλγόριθμος

Ένας αλγόριθμος είναι μια βήμα προς βήμα διαδικασία για την επίλυση ενός προβλήματος, με πεπερασμένο πλήθος βημάτων. Ένας σωστός αλγόριθμος πρέπει:

  • να δέχεται είσοδο (μηδέν ή περισσότερα δεδομένα),
  • να παράγει έξοδο (ένα ή περισσότερα αποτελέσματα),
  • να είναι ορισμένος, δηλαδή να περιέχει σαφείς οδηγίες,
  • κάθε οδηγία του να είναι, μεμονωμένα, εξαιρετικά απλή,
  • να καλύπτει όλες τις δυνατές καταστάσεις εισόδου,
  • και να εξασφαλίζει τον τερματισμό του, σε πεπερασμένο αριθμό βημάτων.

Ένα πρόγραμμα είναι η ακριβής διατύπωση ενός αλγορίθμου σε μια γλώσσα προγραμματισμού. Ένας αλγόριθμος μπορεί να περιγραφεί με φυσική γλώσσα, με διάγραμμα ροής (flowchart), με ψευδοκώδικα, ή απευθείας με κώδικα.

Η υπολογιστική επίλυση ενός προβλήματος περνάει συνήθως από τα εξής στάδια:

  1. Ανάλυση των δεδομένων του προβλήματος.
  2. Μαθηματική διατύπωση του προβλήματος.
  3. Σχεδιασμός ή επιλογή κατάλληλου αλγορίθμου (συνήθως ένα πρόβλημα λύνεται με πολλούς διαφορετικούς αλγορίθμους).
  4. Διατύπωση του αλγορίθμου σε γλώσσα προγραμματισμού, δηλαδή συγγραφή του προγράμματος.
  5. Εκτέλεση του προγράμματος για συγκεκριμένα δεδομένα.
  6. Ερμηνεία των αποτελεσμάτων.

Οι βασικές αλγοριθμικές ενέργειες που συναντάμε σχεδόν σε κάθε αλγόριθμο είναι: είσοδος/έξοδος δεδομένων, πράξεις ή αναθέσεις τιμών σε μεταβλητές, έλεγχος συνθηκών και επιλογή δράσης, επαναληπτική εκτέλεση, και τερματισμός.

1.1 Παράδειγμα: Δυαδική Αναζήτηση (Binary Search)

Ας δούμε έναν πλήρη αλγόριθμο στις τέσσερις μορφές αναπαράστασης που αναφέραμε: φυσική γλώσσα, διάγραμμα ροής, ψευδοκώδικας, και κώδικας.

Πρόβλημα: Δίνεται μια ταξινομημένη λίστα αριθμών v και μια τιμή-στόχος. Να βρεθεί η θέση της τιμής-στόχου μέσα στη λίστα (ή να διαπιστωθεί ότι δεν υπάρχει).

Η αφελής λύση θα ήταν να ελέγξουμε τα στοιχεία ένα-ένα (γραμμική αναζήτηση), κάτι που στη χειρότερη περίπτωση απαιτεί να ελέγξουμε όλα τα στοιχεία. Επειδή όμως η λίστα είναι ταξινομημένη, μπορούμε να είμαστε πολύ πιο αποδοτικοί: συγκρίνουμε τον στόχο με το μεσαίο στοιχείο, και ανάλογα αν ο στόχος είναι μικρότερος ή μεγαλύτερος, αγνοούμε αμέσως το ένα από τα δύο μισά της λίστας. Επαναλαμβάνοντας, ο χώρος αναζήτησης μικραίνει στο μισό σε κάθε βήμα.

Σε φυσική γλώσσα

  1. Όρισε δύο δείκτες, αριστερά (στην αρχή της λίστας) και δεξιά (στο τέλος της λίστας).
  2. Όσο ο δείκτης αριστερά δεν έχει προσπεράσει τον δείκτη δεξιά:
    1. Υπολόγισε το μέσο, τη θέση στη μέση του τρέχοντος διαστήματος [αριστερά, δεξιά].
    2. Αν το στοιχείο στη θέση μέσο είναι ο στόχος, βρέθηκε — τερμάτισε επιστρέφοντας τη θέση μέσο.
    3. Αν ο στόχος είναι μικρότερος από το στοιχείο στη θέση μέσο, ο στόχος (αν υπάρχει) βρίσκεται στο αριστερό μισό: μετακίνησε τον δείκτη δεξιά αμέσως πριν το μέσο.
    4. Αλλιώς, ο στόχος βρίσκεται στο δεξί μισό: μετακίνησε τον δείκτη αριστερά αμέσως μετά το μέσο.
  3. Αν ο δείκτης αριστερά προσπεράσει τον δείκτη δεξιά χωρίς να βρεθεί ο στόχος, τότε ο στόχος δεν υπάρχει στη λίστα.

2 Η Python

Η Python είναι μια γλώσσα προγραμματισμού υψηλού επιπέδου, η οποία:

  • χρησιμοποιεί διερμηνέα (είναι scripting language), και μπορεί να εκτελεστεί είτε ανά εντολή σε διαδραστικό κέλυφος (shell), είτε ως πλήρες αρχείο .py,
  • είναι δυναμική ως προς τον ορισμό τύπου μεταβλητών (δεν χρειάζεται να δηλώσουμε τον τύπο μιας μεταβλητής),
  • έχει απλή σύνταξη, με υποχρεωτική στοίχιση (indentation) που οριοθετεί τα μπλοκ κώδικα,
  • διαθέτει μεγάλη πρότυπη βιβλιοθήκη (standard library) έτοιμων συναρτήσεων.

Αναπτύχθηκε από τον Ολλανδό Guido van Rossum στις αρχές της δεκαετίας του ’90 (πρώτη έκδοση Python 0.9.0, Φεβρουάριος 1991). Ακολούθησαν η Python 2.0 (2000) και η Python 3.0 (2008, μη συμβατή προς τα πίσω με την 2.x), η οποία και χρησιμοποιούμε σήμερα.

Ένα πρόγραμμα Python μπορεί να εκτελεστεί με δύο τρόπους: διαδραστικά, πληκτρολογώντας εντολές μία-μία στο κέλυφος (shell) της Python, που τις διερμηνεύει και τις εκτελεί αμέσως· ή σε λειτουργία script, γράφοντας ολόκληρο το πρόγραμμα σε ένα αρχείο με κατάληξη .py και εκτελώντας το αρχείο συνολικά. Στις σημειώσεις αυτές, τα διαδραστικά πλαίσια κώδικα προσομοιώνουν και τους δύο τρόπους: κάθε φορά που πατάτε “Run Code”, ολόκληρο το περιεχόμενο του πλαισίου εκτελείται σαν script.

Το σύμβολο # ξεκινά ένα σχόλιο: οτιδήποτε βρίσκεται στα δεξιά του δεν λαμβάνεται υπόψη από τον διερμηνέα.

2.1 Μεταβλητές και τύποι

Μια μεταβλητή είναι ένα όνομα που αναφέρεται σε ένα αντικείμενο αποθηκευμένο στη μνήμη, και έχει έναν τύπο (type), ένα όνομα, και μια τιμή. Δημιουργείται με μία εντολή εκχώρησης (assignment): μεταβλητή = τιμή. Στην Python δεν χρειάζεται να δηλωθεί ο τύπος μιας μεταβλητής· προσδιορίζεται αυτόματα, και μπορεί να αλλάξει αν επανεκχωρηθεί τιμή διαφορετικού τύπου:

Κανόνες ονοματολογίας: ένα όνομα μεταβλητής δεν μπορεί να είναι δεσμευμένη λέξη (π.χ. for, if, while), πρέπει να ξεκινά με γράμμα ή κάτω παύλα (_), να περιέχει μόνο γράμματα, αριθμούς και κάτω παύλες (χωρίς κενά ή τελείες), και η Python κάνει διάκριση πεζών/κεφαλαίων (case sensitive).

2.2 Είσοδος με την input

Σε ένα κανονικό πρόγραμμα Python, η συνάρτηση input('μήνυμα') διαβάζει δεδομένα από το πληκτρολόγιο και πάντα επιστρέφει συμβολοσειρά — ακόμα κι αν ο χρήστης πληκτρολογήσει έναν αριθμό. Για να χρησιμοποιηθεί αριθμητικά, πρέπει να μετατραπεί με τις συναρτήσεις int() ή float():

age = input('Δώσε την ηλικία σου: ')   # η age είναι πάντα str
age = int(age)                          # μετατροπή σε int

ή, πιο σύντομα, με άμεση σύνθεση των δύο κλήσεων:

age = int(input('Δώσε την ηλικία σου: '))
Σημείωση

Επειδή τα διαδραστικά πλαίσια αυτών των σημειώσεων εκτελούνται μέσα στον browser, δεν υποστηρίζουν την input(). Σε όλα τα παραδείγματα αυτής της ενότητας, όπου κανονικά θα χρησιμοποιούσαμε input(), ορίζουμε απευθείας μια μεταβλητή με μια τιμή — προσομοιώνοντας το αποτέλεσμα μιας κλήσης input().
